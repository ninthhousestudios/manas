## key decisions made this session

1. **mcpjungle PR strategy: upstream first + fork fallback.** Don't gate manas progress on upstream review queue. PR #250 is open; we run on the fork branch if needed.
2. **opencode adapter deferred to phase 2.** Two-process lifecycle is materially more complexity than the other three; not worth the cost for v1. Phase 1 ships CC + Codex + Gemini.
3. **manas-cli admin credential** is folded into scaffold task /4 (not a separate task). Decisions to make there: where the admin token lives (`~/.manas/admin-token`, env var, keyring), how it's bootstrapped (`manas init`?), and how `manas health` warns if mcpjungle is in dev mode.
4. **Boot contract §3 corrected.** `MANAS_MCP_ENDPOINT` is mode-specific (group-URL), not mode-neutral. Token does not determine TG; URL does (until PR #250 lands strict-mode enforcement).
5. **Yojana is the new tracker.** docs/todo.md is legacy. New work goes into yojana projects with depends_on edges.
